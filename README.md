# curriculo-3d

Currículo interativo em three.js: role a página e cada experiência vira uma cena animada, com
mensagens percorrendo tubos entre produtores, partições do Kafka e consumidores, documentos sendo
anonimizados, pods escalando com a carga e a Black Friday do cálculo de frete.

```bash
mise install
npm install
npm run dev
```

Publicado em https://sobre.lucaspolo.dev a cada push na `main`.

Detalhes de arquitetura, publicação e armadilhas em [AGENTS.md](AGENTS.md).
